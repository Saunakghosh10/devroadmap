# devroadmap

A comprehensive Full Stack Developer Roadmap built with Vite + React.

## Features

- **6 Learning Tracks**: JavaScript, TypeScript, React, Next.js, Backend, and Web Essentials
- **Roadmap Phases**: Step-by-step learning paths for each technology
- **Design Patterns**: Key concepts with code examples and interview explanations
- **Interview Questions**: Practice Q&A with expandable answers
- **Flashcards**: Deep-dive web essentials with quiz mode
- **Connection Map**: Visual links showing how concepts connect across the stack

## Tech Stack

- Vite
- React 18
- Tailwind CSS
- Framer Motion
- react-syntax-highlighter
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
